# Guru Box

PWA para el gimnasio **Guru Box**.

## Funcionalidades previstas

- Control de alumnos y mensualidades
- Avisos automáticos de vencimiento por Telegram
- App instalable en iPhone, Android y escritorio
- Uso principal desde el celular

## Stack

- Frontend: HTML + CSS + JavaScript (PWA)
- Base de datos: Firebase Firestore
- Hosting: GitHub Pages
- Avisos programados: GitHub Actions + Telegram Bot
